Editor Java - edita texturas, textos e arquivos de jogos .jar no Android.
Enviar ao GitHub (Termux), dentro desta pasta:
  bash gitpush.sh https://github.com/hackproff23-max/Editor-java.git
Depois so: bash gitpush.sh   (use FORCE=1 se o GitHub recusar)
O APK sai em Actions > build > artefato EditorJava-apk.
