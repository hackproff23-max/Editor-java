Editor Java - menu: Editar jogos (texturas/textos de .jar) e Editar PES (nomes de jogadores e times).
Enviar ao GitHub (Termux), dentro desta pasta:
  bash gitpush.sh
(1a vez: bash gitpush.sh https://github.com/hackproff23-max/Editor-java.git ; FORCE=1 se o GitHub recusar)
O APK sai em Actions > build > artefato EditorJava-apk.
